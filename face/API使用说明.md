# 🚀 人脸识别与表情识别系统 - 前端调用完整指南

## 📚 前言

本系统提供了三个完全独立的功能模块，每个模块都支持多种输入源。前端开发者可以根据需要选择合适的接口进行调用，实现人脸识别、表情识别和综合识别功能。

## �� 系统功能概述

### 功能模块
1. **人脸识别模块** - 识别图片中的人是谁
2. **表情识别模块** - 识别图片中的人是什么表情  
3. **综合识别模块** - 同时识别身份和表情

### 支持的输入源
- **图片文件**：JPG、JPEG、PNG、BMP、TIFF等格式
- **视频文件**：MP4、AVI、MOV、WMV等格式
- **实时视频流**：RTSP流地址
- **本地摄像头**：电脑内置或外接摄像头

## 🌐 接口地址说明

### 基础地址
所有接口都在 `http://localhost:8000` 这个地址上运行

### 接口分组
- **人脸识别接口组**：以 `/face/` 开头
- **表情识别接口组**：以 `/emotion/` 开头  
- **综合识别接口组**：以 `/combined/` 开头

## 📋 详细接口列表

### 人脸识别接口组

#### 图片识别接口
- **接口地址**：`/face/recognize_image`
- **请求方法**：POST
- **功能说明**：识别图片中的人脸，返回身份信息
- **输入参数**：图片文件（参数名必须是 `file`）
- **返回结果**：包含身份、相似度、人脸框位置等信息

#### 视频识别接口
- **接口地址**：`/face/recognize_video`
- **请求方法**：POST
- **功能说明**：识别视频中的人脸，逐帧分析
- **输入参数**：视频文件（参数名必须是 `file`）
- **返回结果**：包含每帧的人脸识别结果

#### RTSP实时流接口
- **接口地址**：`/face/recognize_rtsp`
- **连接方式**：WebSocket
- **功能说明**：实时识别RTSP视频流中的人脸
- **输入参数**：RTSP流地址
- **返回结果**：实时返回识别结果

#### 本地摄像头接口
- **接口地址**：`/face/recognize_camera`
- **连接方式**：WebSocket
- **功能说明**：实时识别本地摄像头中的人脸
- **输入参数**：摄像头ID（通常是0）
- **返回结果**：实时返回识别结果

## 🔧 前端调用步骤详解

### 第一步：准备工作

#### 环境要求
- 确保后端服务器已经启动（运行 `python3 start_server.py`）
- 服务器地址是 `http://localhost:8000`
- 浏览器支持现代JavaScript特性

#### 文件准备
- 选择要识别的图片或视频文件
- 确保文件格式正确
- 图片中必须包含清晰的人脸

### 第二步：选择调用方式

#### 图片识别调用
1. 在网页上创建文件选择框
2. 设置文件选择框只接受图片格式
3. 用户选择包含人脸的图片
4. 根据需求选择对应的识别接口

#### 视频识别调用
1. 在网页上创建文件选择框
2. 设置文件选择框只接受视频格式

1. 在网页上创建输入框（用于RTSP地址或摄像头ID）
2. 用户输入RTSP流地址或选择摄像头
3. 建立WebSocket连接
4. 实时接收识别结果

### 第三步：构建请求数据

#### 文件上传请求
1. 创建FormData对象
2. 将选择的文件添加到FormData中
3. 参数名必须设置为 `file`
4. 设置正确的请求头

#### WebSocket连接
1. 创建WebSocket对象
2. 连接到对应的WebSocket地址
3. 发送配置信息（RTSP地址或摄像头ID）
4. 监听返回的消息

### 第四步：发送请求

#### HTTP请求发送
1. 使用fetch函数发送POST请求
2. 请求地址是完整的接口地址
3. 请求体是FormData对象
4. 设置正确的请求方法

#### WebSocket消息发送
1. 等待WebSocket连接建立
2. 发送JSON格式的配置信息
3. 确保消息格式正确
4. 处理连接错误

### 第五步：处理响应结果

#### 解析返回数据
1. 等待服务器返回结果
2. 将返回的JSON数据解析出来
3. 检查返回结果的状态
4. 提取需要的信息

#### 显示识别结果
1. 在页面上创建结果显示区域
2. 格式化显示识别结果
3. 处理多个人脸的情况
4. 显示错误信息（如果有）

## 📊 返回结果格式说明

### 人脸识别结果格式

#### 单个识别结果包含
- **box**：人脸框位置坐标，格式为 [左上角x, 左上角y, 右下角x, 右下角y]
- **confidence**：人脸检测的置信度，范围0到1，越高越准确
- **identity**：识别出的身份，如果数据库中没有这个人则显示"Unknown"
- **similarity**：相似度分数，范围0到1，越高越相似

#### 完整响应格式
```json
{
  "success": true,
  "faces": [
    {
      "box": [100, 150, 200, 250],
      "confidence": 0.95,
      "identity": "张三",
      "similarity": 0.87
    }
  ],
  "total_faces": 1
}
```

### 表情识别结果格式

#### 单个识别结果包含
- **box**：人脸框位置坐标
- **confidence**：人脸检测的置信度
- **emotion**：识别出的表情类型
- **emotion_confidence**：表情识别的置信度

#### 表情类型说明
- **happy**：开心
- **sad**：悲伤
- **angry**：愤怒
- **surprise**：惊讶
- **fear**：恐惧
- **disgust**：厌恶
- **neutral**：中性

#### 完整响应格式
```json
{
  "success": true,
  "faces": [
    {
      "box": [100, 150, 200, 250],
      "confidence": 0.95,
      "emotion": "happy",
      "emotion_confidence": 0.92
    }
  ],
  "total_faces": 1
}
```

### 综合识别结果格式

#### 单个识别结果包含
- 人脸识别的所有信息
- 表情识别的所有信息
- 完整的人脸分析结果

#### 完整响应格式
```json
{
  "success": true,
  "faces": [
    {
      "box": [100, 150, 200, 250],
      "confidence": 0.95,
      "identity": "张三",
```

#### JavaScript实现
```javascript
// 文件选择和预览
document.getElementById('imageFile').addEventListener('change', function(e) {
    const file = e.target.files[0];
    if (file) {
        const reader = new FileReader();
        reader.onload = function(e) {
            const img = document.getElementById('previewImage');
            img.src = e.target.result;
            img.style.display = 'block';
            document.getElementById('resultCanvas').style.display = 'none';
        };
        reader.readAsDataURL(file);
    }
});

// 人脸识别
async function recognizeFace() {
    const file = document.getElementById('imageFile').files[0];
    if (!file) {
        alert('请先选择图片');
        return;
    }
    
    const formData = new FormData();
    formData.append('file', file);
    
    try {
        const response = await fetch('http://localhost:8000/face/recognize_image', {
            method: 'POST',
            body: formData
        });
        
        const result = await response.json();
        displayFaceResult(result);
        drawFaceBoxes(result);
        
    } catch (error) {
        console.error('识别失败:', error);
        alert('识别失败: ' + error.message);
    }
}

// 显示识别结果
function displayFaceResult(result) {
    const resultDiv = document.getElementById('recognitionResult');
    if (result.success && result.faces.length > 0) {
        let html = '<h3>识别结果:</h3>';
        result.faces.forEach((face, index) => {
            html += `
                <div class="face-result">
                    <h4>人脸 ${index + 1}</h4>
                    <p>身份: ${face.identity}</p>
                    <p>相似度: ${(face.similarity * 100).toFixed(2)}%</p>
                    <p>置信度: ${(face.confidence * 100).toFixed(2)}%</p>
                </div>
            `;
        });
        resultDiv.innerHTML = html;
    } else {
        resultDiv.innerHTML = '<p>未检测到人脸或识别失败</p>';
    }
}

// 绘制人脸框
function drawFaceBoxes(result) {
    if (!result.success || result.faces.length === 0) return;
    
    const img = document.getElementById('previewImage');
    const canvas = document.getElementById('resultCanvas');
    const ctx = canvas.getContext('2d');
    
    canvas.width = img.naturalWidth;
    canvas.height = img.naturalHeight;
    canvas.style.display = 'block';
    
    // 绘制原图
    ctx.drawImage(img, 0, 0);
    
    // 绘制人脸框和标签
    result.faces.forEach((face, index) => {
        const [x1, y1, x2, y2] = face.box;
        
        // 绘制人脸框
        ctx.strokeStyle = '#00ff00';
        ctx.lineWidth = 3;
        ctx.strokeRect(x1, y1, x2 - x1, y2 - y1);
        
        // 绘制标签背景
        ctx.fillStyle = 'rgba(0, 255, 0, 0.8)';
        ctx.fillRect(x1, y1 - 30, 200, 25);
        
        // 绘制标签文字
        ctx.fillStyle = 'white';
        ctx.font = '16px Arial';
        ctx.fillText(`${face.identity} (${(face.similarity * 100).toFixed(1)}%)`, x1 + 5, y1 - 10);
    });
}
```

## ❌ 错误处理说明

### 常见错误类型

#### 文件相关错误
- **文件格式不支持**：选择的文件格式不在支持范围内
- **文件损坏**：上传的文件无法正常读取
- **文件过大**：文件大小超出处理限制
- **文件为空**：上传的文件内容为空

#### 网络相关错误
- **服务器未启动**：后端服务没有运行
- **网络连接失败**：无法连接到服务器
- **请求超时**：请求处理时间过长
- **连接断开**：WebSocket连接意外断开

#### 参数相关错误
- **缺少文件**：没有选择要识别的文件
- **参数格式错误**：传递的参数格式不正确
- **参数缺失**：必需的参数没有提供
- **参数类型错误**：参数类型不匹配

#### 服务器相关错误
- **模型加载失败**：AI模型无法正常加载
- **内存不足**：服务器内存资源不足
- **处理异常**：识别过程中出现未知错误
- **数据库错误**：人脸数据库访问失败

### 错误处理策略

#### 前端错误处理
1. **输入验证**：在发送请求前验证文件格式和大小
2. **网络检测**：检查网络连接状态
3. **超时设置**：为请求设置合理的超时时间
4. **重试机制**：网络错误时自动重试
5. **用户提示**：显示友好的错误信息

#### 错误信息显示
1. **错误类型**：明确告知用户错误的具体类型
2. **解决建议**：提供解决错误的建议和步骤
3. **重试选项**：提供重新尝试的选项
4. **联系支持**：提供技术支持联系方式

## 💡 使用技巧和最佳实践

### 提高识别准确率

#### 图片质量要求
- **分辨率**：选择足够高分辨率的图片
- **清晰度**：确保图片清晰，没有模糊
- **光线**：光线要充足，避免过暗或过亮
- **角度**：人脸角度要正面，避免侧脸
- **遮挡**：避免人脸被遮挡或部分缺失

#### 视频质量要求
- **帧率**：选择合适帧率的视频
- **分辨率**：视频分辨率要足够高
- **稳定性**：避免画面抖动或模糊
- **时长**：视频时长要适中，不要过长

## 🔍 故障排除指南

### 常见问题解决

#### 服务器无法启动
1. **检查端口占用**：确认8000端口没有被其他程序占用
2. **检查依赖**：确认所有Python包都已正确安装
3. **检查模型文件**：确认模型文件路径正确且文件完整
4. **检查权限**：确认有足够的文件读写权限

#### 识别结果不准确
1. **检查图片质量**：确保图片清晰，人脸足够大
2. **检查光线条件**：确保光线充足，避免过暗或过亮
3. **检查人脸角度**：确保人脸角度正面，避免侧脸
4. **检查模型状态**：确认模型已正确加载

2. **检查流地址**：确认RTSP地址格式正确且可访问
3. **检查防火墙**：确认防火墙没有阻止连接

#### 前端页面无法访问

3. **检查浏览器兼容性**：确认浏览器支持现代特性
4. **检查网络配置**：确认网络配置正确
