# 人脸识别与表情识别系统 - 前端开发指南

## 🎯 快速开始

### 服务器信息
- **基础URL**: `http://127.0.0.1:8000`
- **API文档**: `http://127.0.0.1:8000/docs`
- **前端演示**: `http://127.0.0.1:8000/frontend`

### 启动服务器
```bash
cd Backend
python start_server.py
```

## 📋 核心API接口

### 1. 人脸识别 - 图片
```javascript
// POST /face/recognize_image
const formData = new FormData();
formData.append('file', imageFile);

fetch('http://127.0.0.1:8000/face/recognize_image', {
  method: 'POST',
  body: formData
})
.then(response => response.json())
.then(data => console.log(data));
```

## 🔄 WebSocket实时流

### 人脸识别 - RTSP流
```javascript
const ws = new WebSocket('ws://127.0.0.1:8000/face/recognize_rtsp');

ws.onopen = function() {
  ws.send(JSON.stringify({
    "rtsp_url": "rtsp://192.168.1.100:554/stream"
  }));
};

ws.onmessage = function(event) {
  const data = JSON.parse(event.data);
  console.log('识别结果:', data);
};
```

### 人脸识别 - 本地摄像头
```javascript
const ws = new WebSocket('ws://127.0.0.1:8000/face/recognize_camera');

ws.onopen = function() {
  ws.send(JSON.stringify({
    "camera_id": 0
  }));
};
```

## 🔧 错误处理

```javascript
function handleApiError(error) {
  if (error.response) {
    console.error('API错误:', error.response.data.error);
    showErrorMessage(error.response.data.error);
  } else if (error.request) {
    console.error('网络错误:', error.message);
    showErrorMessage('网络连接失败，请检查网络设置');
  } else {
    console.error('未知错误:', error.message);
    showErrorMessage('发生未知错误，请稍后重试');
  }
}
```

## 📝 注意事项

1. **CORS已配置**：系统已配置跨域支持，前端无需额外设置
2. **文件大小限制**：最大100MB
3. **支持格式**：JPG, PNG, MP4, AVI等
4. **实时流**：支持RTSP和本地摄像头
5. **表情类型**：高兴、悲伤、愤怒、惊讶、恐惧、厌恶、中性
